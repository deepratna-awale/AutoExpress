# AutoExpress for AUTOMATIC1111, Forge, reForge and SD.Next

1. Install [ADetailer](https://github.com/Bing-su/adetailer) if you haven't already.
2. Install AutoExpress, either way works:
   - **Extensions → Available**, press **Load from**, search for **AutoExpress** and press **Install**.
   - **Extensions → Install from URL** with `https://github.com/deepratna-awale/AutoExpress`, or clone the repository into `extensions/`.
3. Restart the WebUI and open the **AutoExpress** tab.
4. Drop in a character image. Prompt, checkpoint, sampler, steps, CFG and seed are filled in from the image's metadata when it has any.
5. Pick a [prompt style](prompt-styles.md) (**auto** picks it from the checkpoint) and the expressions you want, then press **Generate**.

<p align="center">

</p>

Images are saved to `outputs/autoexpress/<character name>/`, with the generation parameters embedded in each PNG. You can change that folder under **Settings → AutoExpress**. A labelled sprite sheet is saved next to them when that option is ticked.

With **Expression LoRAs** ticked, the matching [expression LoRA](expression-loras.md) is downloaded into the WebUI's LoRA folder (`--lora-dir`, or `models/Lora`) the first time and added to the prompt. If a LoRA can't be used, for example because no [Civitai key](expression-loras.md#civitai-key) was found, the status line says why.
