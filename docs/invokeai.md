# AutoExpress for InvokeAI

Open the **Nodes** tab, choose **Git Repository URL**, paste `https://github.com/deepratna-awale/AutoExpress.git` and press **Install**. On InvokeAI versions without the Custom Node Manager, clone the repository into `<INVOKEAI_ROOT>/nodes/` and restart InvokeAI.

The **AutoExpress Expression Prompts** node outputs one prompt per expression in the chosen prompt style, plus the matching negative prompt, ready to iterate over in a face inpainting graph.
